# BA 00 – Project Context

## Mục đích thư mục

Thư mục này thiết lập nền tảng dự án ReMarket: bối cảnh, lý do đầu tư phân tích/thiết kế, phạm vi hệ thống, các giả định, ràng buộc, phụ thuộc và bộ thuật ngữ chuẩn hóa (Glossary).

1. Đọc **Project Brief** và **Scope and Boundaries** trước khi đọc các yêu cầu chi tiết.
2. Mọi quyết định và câu hỏi mở kỹ thuật tại đây được quản lý tập trung và truy vết sang `02_business-analysis/open-questions-and-decisions.md`.
3. Thuật ngữ trong toàn bộ tài liệu BA phải tuân thủ nghiêm ngặt theo **Glossary**.
